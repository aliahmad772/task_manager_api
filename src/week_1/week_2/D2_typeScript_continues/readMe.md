Today I have learned the following topics:

1. Primitive and Referencing:
    TypeScript has primitive types like string, number, boolean, null, undefined, and symbol. It also has reference types like arrays, objects, and functions.

2. Tuples: 
    TypeScript allows you to define a tuple type, which is an array with a fixed number of elements of specific types.

3. Enum:
    TypeScript allows you to define an enum type, which is a way to define a set of named constants.
