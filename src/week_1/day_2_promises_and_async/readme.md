Today i have learned about promises, async/await and error handling in advanced level.

1. Promise: Promises are used for managing background tasks. Promises provides two functions resolve() and reject(). If the promise is fullfilled it gives result and if rejected if gives an error.

2. Async/await: It handles the block of code or function asychroniously. It is just similer to promises but it has more clear syntax as compared to promises. Here await keyword is used before the code or function until it produces a result.

3. Error handling: We use try and catch here for better error handling and its gives us more organized way for handling error and easyly understand it.
