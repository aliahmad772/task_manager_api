1. Extending Interface: TS provides us to creating new interface based on existing one.

2. Type Aliases: Type aliases allow us to create a new name for a type. This can be useful for simplifying complex types or creating more readable code.

3. Intersection Types: Intersection types allow us to combine multiple types into one. This can be useful for creating more complex types that have properties from multiple sources.

4. Class: Class is a prototype based on which we can create multiple instances/objects.

5. Contructor: Constructor is a method in class that is used for creating and initilaizing objects.

6. Access Modidiers:
    Public: Propertise and methods of a class that can be access from every where.

    Private: Propertise and methonds that can be be accessed only from a class itself.
